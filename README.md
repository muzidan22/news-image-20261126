## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That places `assets/entry.png` (1024x1024, the front page)
at `out/entry.png`. The output is byte-for-byte identical
on every run: the script only copies a file, using the
Python standard library, with no network and no randomness.
