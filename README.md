## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That copies `assets/entry.png` (1024x1024, the front page)
to `out/entry.png`. The result is byte-for-byte identical on
every run: the script only copies one file, using the Python
standard library, with no network and no randomness.
